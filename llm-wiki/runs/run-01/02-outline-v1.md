# Run 01｜節點 4：整理重點（大綱 v1）

1. 封面：抽卡前，先知道你的 5 個權益
2. 開場：你按下「同意」的條款，其實是定型化契約；有些條款寫了也無效 ← 定型化契約
3. 權益 1｜機率要用百分比公開，附提示語；免費寶箱＋付費鑰匙也算 ← 機率揭露
4. 權益 2｜保底、天井是什麼；政府鼓勵但不強制 ← 保底與天井
5. 權益 3｜付費點數不能設期限；不玩了，未使用點數 30 日內退 ← 點數與退款
6. 權益 4｜開始遊戲後 7 日內可解除並退未使用點數；抽掉的不能反悔 ← 七天解除與數位內容例外
7. 權益 5｜帳號被盜、停權最長 7 日、bug 要賠；可調閱遊戲歷程 ← 帳號停權與程式錯誤
8. 案例：天堂M 實測約 2.3% vs 公告 10% ← 案例-天堂M機率爭議
9. 出事怎麼辦：業者 15 日 → 消保官 → 調解；1950 ← 申訴管道
10. 業者不改正：3 萬～30 萬，再不改 5 萬～50 萬 ← 主管機關與罰則
11. 小測驗 3 題 ← 常見迷思
12. 重點回顧＋來源
